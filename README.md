# Wast2

> **A simple, powerful scripting language.**

Wast2는 간단한 문법과 높은 확장성을 목표로 만들어진 경량 프로그래밍 언어입니다.
---

## Features

* 간단하고 직관적인 문법
* 일반적인 프로그래밍 가능
* 수치 계산 및 데이터 처리
* 함수와 제어문 지원
* 자동화 및 스크립팅

---

## AI

Wast2는 단순한 명령 자동화용 스크립트에만 사용할 수 있는 언어가 아닙니다.
C++ Library 문법을 사용하면 만들수도 있습니다. 

---

## Example

```wast
function add(a, b) (
    return a + b
)

result = add(10, 20)

print(result)
```

간단한 코드는 최대한 짧게 작성하면서도, 필요할 때는 복잡한 프로그램을 만들 수 있도록 설계되었습니다.

---

## Why Wast2?

Wast2의 목표는 복잡한 문법을 외우는 데 시간을 쓰기보다 **아이디어를 코드로 빠르게 옮길 수 있는 언어**를 만드는 것입니다.

Wast2는 다음과 같은 용도로 사용할 수 있습니다.

* 게임 스크립팅
* 자동화
* 데이터 처리
* 프로토타이핑
* 개발 도구
* 애플리케이션 스크립팅
  

---

## Philosophy

Wast2는 다음을 중요하게 생각합니다.

> **Simple syntax. Powerful programs.**

배우기는 쉽지만 실제 프로그램을 만들 수 있어야 합니다.
